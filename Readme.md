# Smart Village Civic Issue Management System

A MERN stack-based civic issue management application that allows citizens to report local issues and enables administrators and field workers to manage, track, and resolve complaints.

## Features

* Citizen registration and login
* JWT-based authentication and role-based access
* Civic complaint submission
* Complaint category and priority management
* Image and location support
* Admin complaint management
* Department and field-worker assignment
* Complaint status tracking
* Before/after resolution proof
* AI-based complaint category and priority suggestions
* RESTful APIs
* MongoDB database
* Responsive React frontend
* Secure password handling using bcrypt
* Git/GitHub based development
